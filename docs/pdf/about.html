동향 용어집과의 관계

참고한 것은 선정 방법론(빈도·지속성 신호, 토픽 쿼터, 개념어 중심)입니다. 표제어 목록은 가져오지 않았고, PDF 코퍼스 등장 빈도로 다시 뽑았습니다. 정의는 같은 리포지토리 원문입니다.

파이프라인

  1. extract_pdf_corpus_candidates.py — 전체 PDF n-gram · df · gloss_df
  2. extract_pdf_def_sections.py — Glossary / Key Definitions / 법령 정의조 등
  3. select_pdf_glossary.py — 점수·쿼터 선정 → 원문 정의 매칭
  4. pdf_localize.py — 영문 표제어·정의 한글화
  5. build_pdf_site.py — 이 사이트

재빌드: ./run_pdf_build.sh

점수

corpus-frequency → score → bucket-quota → verbatim definitions

  • df — 용어가 등장한 서로 다른 PDF 수

  • year_span — 출판연도 분산
  • 정의 매칭은 선정 후 단계이며, 정의 섹션 우선·본문 정의형 문장 보조
  • 한글화 — 영문 표제어에 번역어, 영문 정의에 편집 대역(quote_ko) 병기. 원문은 유지
